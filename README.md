# ❄️ Интерактивный 3D-стенд: «Как устроен кондиционер»

Познавательное интерактивное 3D веб-приложение для детей (8+ лет) и взрослых, наглядно объясняющее термодинамику и внутреннее устройство современной сплит-системы.

Разработано в полупрозрачном футуристическом «хай-тек» стиле на базе **Three.js** и процедурного звукового движка **Web Audio API**.

---

## 🌟 Основные возможности

1. **Полная сплит-система в разрезе (комната + стена + улица)**:
   - **Внутренний блок**: тангенциальный барабанный вентилятор («беличье колесо»), испаритель, подвижные жалюзи (шторка) с автоматическим закрытием.
   - **Межблочная трасса**: медные фреоновые трубки сквозь стену с индикацией фазового состояния (жидкость / газ) и давления.
   - **Внешний блок**: герметичный роторный компрессор, конденсатор, расширительный дроссель, мощный уличный вентилятор.

2. **Высокодетализированный уличный вентилятор**:
   - 3 аэродинамические серповидные лопасти с круткой профиля (угол атаки от $34^\circ$ у ступицы до $16^\circ$ на концах).
   - Обтекаемый носовой кок (spinner cone).
   - Аэродинамический круглый диффузор-раструб (bellmouth shroud).
   - Защитная концентрическая решетка и стационарный электромотор.

3. **Физическая инерция и затухание (3–4 сек)**:
   - Плавный разгон и торможение лопастей маховика под сопротивлением воздуха.
   - Потоки воздуха плавно растворяются (opacity fade) при отключении.
   - Шторка внутреннего блока автоматически герметично закрывается в горизонтальное положение при выключении и открывается при запуске.

4. **Неоновая визуализация термодинамического цикла**:
   - Тысячи светящихся частиц показывают циркуляцию хладагента:
     - 🔴 **Горячий газ высокого давления** (после компрессора)
     - 🟠 **Теплая жидкость** (после конденсатора)
     - 🔵 **Ледяная жидкость низкого давления** (после дросселя)
     - 🔷 **Холодный пар** (после испарителя)
   - Термографические потоки воздуха: забор теплого комнатного воздуха сверху и выдув холодного вниз.

5. **Интерактивный пульт управления**:
   - ⏻ Включение / выключение с сохранением физики и звуковых эффектов.
   - ❄️ / ☀️ / 🌀 Режимы: Охлаждение, Обогрев (с мгновенным реверсом термодинамического цикла) и Вентиляция.
   - ⚡ Турбо-режим максимальной мощности.
   - Регулировка температуры (16°C – 30°C) и скорости обдува (4 ступени).

6. **Обучающие карточки с простыми объяснениями**:
   - Кликабельные узлы в 3D-сцене и нижняя панель быстрого выбора.
   - Плавный кинематографический подлет камеры к выбранной детали.
   - Понятные аналогии для ребенка 8 лет.

7. **Процедурный звук (Web Audio API)**:
   - Двухтональный электронный «пик» пульта ДУ.
   - Низкочастотный гул компрессора с динамической модуляцией оборотов.
   - Шелест воздушного потока при изменении скорости.
   - Плавное затухание тона (глиссандо) при остановке.

8. **Полная поддержка iPad и планшетов**:
   - Управление жестами: вращение пальцем, pinch-to-zoom двумя пальцами.
   - Оптимизированный сенсорный интерфейс.
   - Встроенный **Service Worker (PWA)** для работы офлайн без интернета и ноутбука.

## 🚀 Как запустить

### На компьютере (Mac / PC)

Самый быстрый способ: просто открыть `index.html` в любом современном браузере (Chrome, Safari, Firefox, Edge).

В терминале Mac:
```bash
open index.html
```

---

### На iPad (в локальной сети с Mac)

1. Убедитесь, что Mac и iPad в одной сети Wi-Fi.
2. В терминале в папке проекта запустите локальный сервер:
   ```bash
   python3 -m http.server 8080
   ```
3. Узнайте локальный IP-адрес вашего Mac (например, через `ipconfig getifaddr en0`).
4. На iPad в **Safari** откройте:
   ```text
   http://<IP-вашего-Mac>:8080
   ```
5. Чтобы приложение открывалось на весь экран без адресной строки Safari:
   - Нажмите кнопку **«Поделиться»** (квадрат со стрелочкой вверх).
   - Выберите **«На экран «Домой»»** (Add to Home Screen).

---

### Полная автономная работа на iPad без ноутбука (Офлайн)

Благодаря встроенному `sw.js` (PWA):
1. Откройте приложение на iPad один раз через Safari по шагам выше.
2. Добавьте его на экран «Домой».
3. iPad автоматически сохранит все ресурсы в офлайн-кэш.
4. Теперь ноутбук можно выключить — иконка на рабочем столе iPad будет запускать симулятор автономно в любое время!
